# AI Bug Fixer

AI-powered repository-aware debugging platform built using:

- FastAPI
- React
- Monaco Editor
- FAISS Vector Database
- AST Parsing
- RAG Architecture
- Dependency Graph Intelligence

## Features

- Multi-language debugging
- Repository upload
- Semantic code retrieval
- Runtime validation
- AI-generated fixes
- Dependency graph analysis

## Tech Stack

Frontend:
- React
- TailwindCSS
- Monaco Editor

Backend:
- FastAPI
- Sentence Transformers
- FAISS
- OpenRouter / DeepSeek
